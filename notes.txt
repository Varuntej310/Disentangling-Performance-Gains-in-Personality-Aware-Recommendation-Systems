creating conda env:

conda create -n gpu python=3.10 -y
conda activate gpu


The tmux workflow:

Step 1: Start a tmux session

$ tmux new -s work

What happens:

You enter a tmux session named work. It looks like a normal terminal. But it’s now persistent. Nothing visually dramatic happens. That’s normal.

Step 2: Do your normal setup INSIDE tmux

$ conda activate gpu
$ export CUDA_VISIBLE_DEVICES=3

>>> print(torch.cuda.get_device_name(0))
NVIDIA A100-PCIE-40GB
>>> print(torch.cuda.get_device_name(1))
NVIDIA A100-PCIE-40GB
>>> print(torch.cuda.get_device_name(2))
NVIDIA A100-PCIE-40GB
>>> print(torch.cuda.get_device_name(3))
NVIDIA A100-PCIE-40GB
>>> print(torch.cuda.get_device_name(4))
Tesla V100-PCIE-32GB
>>> print(torch.cuda.get_device_name(5))
Tesla V100-PCIE-32GB
>>> print(torch.cuda.get_device_name(6))
Tesla V100-PCIE-32GB


Now, environment is active, GPU is locked, safe to run jobs

Step 3: Detach safely 

Press:

Ctrl + B
then release
then press D

This detaches you from tmux, DOES NOT stop your code, returns you to normal shell. You can now close SSH, lose internet, go home. Your job keeps running.

Step 4: Reattach later. When you reconnect:

$ tmux attach -t work

You’re back exactly where you left off.
